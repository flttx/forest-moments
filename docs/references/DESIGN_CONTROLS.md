# 森林拾光参考图落地约束

更新：2026-10-24。状态：历史参考设计与本轮树木修订并存；除注明的四阶段树运行高度，其余尺寸为早期灰盒起点，不是实测模型数据。

## 参考优先级

专题主图与本文件的明确约束 → 当前环境总板的配色和构成 → 整体概念 v2 的空间气氛。历史参考不继续决定结构。总板是插画汇总，不能替代单体尺寸和施工关系；需要多视图时，从同一个 Blender 模型旋转渲染，避免不同生成画面互相镜像或结构漂移。

## 工坊与瞭望塔

- 工坊：主屋暂按宽 5m、深 4m，附棚宽约 2m。站在正门外看向建筑时，附棚固定在左侧；低石基、浅入口台阶、开放工作台。取消烟囱；门扇、台阶、侧棚后部衔接由模型统一确定，不沿用历史左右视图。
- 瞭望塔：四根主木柱支撑开放平台，小石脚分离，底部不设封闭房间和石砌塔体。平台高度暂按约 6m、屋顶最高约 8m；外置两段折返楼梯、中间平台、连续扶手及顶部入口必须真正连通。图中交叉支撑不能侵入楼梯和角色通路。
- 图内台阶数量和透视不作为施工数据。先以浣熊碰撞体测试坡度、踏步、入口净宽和相机，再制作细节。

## 种树与植被

- 可种植树统一为圆冠阔叶树，按用户追加要求改为四阶段：单茎未分叉小苗 0.22 m、分叉树苗 0.55 m、幼树 1.5 m、成树 3 m；已通过 Blender 归一到这些运行高度，证据见报告 5.28。
- 四阶段保持裂叶、暖棕树皮和分枝语言，阶段切换要有明确形体变化；第一阶段只有主茎、叶柄和顶芽，不提前长出木质侧枝。原三阶段板作为风格来源，细长幼松只保留历史参考，不混入种植成长链。
- 环境仍以高松/普通松为主，少量阔叶。重复树石实例化，控制道路两侧和建筑前方遮挡；不按概念插画逐片复制叶、花和草。

## 浣熊与动物

- 浣熊保留面罩、圆脸、绿色短披肩和下垂环纹尾巴；鞋部、衣褶简化。正背面张臂间隙作为建模目标；侧视图投影重叠不能作为肢体粘连依据。
- 毛发以少量整体毛块和贴图表现；不按图内细毛逐根建模。披肩与手臂分离，尾根位置、尾巴粗细和环纹数量在唯一模型上固定，不能把插画视角差异当成结构变化。
- 羊肩高暂按 0.75m、鸡全高约 0.35m，模型中测量，不直接照图像像素比。奶油色羊毛、深灰脸/腿；鸡为棕橙羽色与红冠。羊毛和鸡翅采用大块形体，避免密集小几何。
- 走跑、坐姿、握竿、划桨和尾巴自然性须通过实际绑定与动作验证，参考图不构成动画通过证据。

## 池塘码头和海岸

- 码头以组装主图确定：岸边缓坡接入、连续甲板，靠船侧开放；路灯避开上船区及抛竿路线。栈桥净宽暂按 1.5m、端部平台约 2m 方形，最终按角色与船实测。
- 近岸浅水和甲板高差需要同时满足上下船；不要把图中水下岩石直接放进舟行区域。船身统一为暗青绿外壳、浅色舷边、暖木内舱。
- 海岸使用连续岩体、局部散石和缓坡沙湾；海水浅深过渡及浪花与池塘分开。池塘岸有湿土、少量芦苇、缓坡和埋入地面的圆石，不使用海浪泡沫或海生附着物。

## 交互接触与参考边界

- 划桨：坐骨落在座位、双脚在船内，双手分别握 T 形柄与桨杆；尾巴需有真实容纳空间，不穿船底。图中部分接触被船舷遮挡，必须用侧向模型视角补验。
- 钓鱼：双脚落在甲板、手握竿柄/轮座，鱼线从导环经竿尖到浮漂；抛竿轨迹不穿灯柱与栏杆。
- 牧场门：胸口附近高度，铰链与门闩分开、开启空间和通路可达；喂食槽设在围栏边，保证手、草料、羊头能接触而身体不穿栏。
- 环境板、成长板、动物板与交互板均含多个对象或场景，不能整张作为单体生成输入。先选定主体，制作独立输入或在 Blender 中按主图建模。
