# Living Competition Report

读取 docs/report/PROJECT_REPORT.md、docs/REPORT_WORKFLOW.md、PROGRESS.md 与 PRD。实施结束后必须：
1. 更新报告当前实现清单，逐项区分计划、几何占位、实现待验证、已验证。
2. 对任何实际生成的 Lux3D 资产补充生成历史、积分/许可证、原版与优化版、骨骼/网格/渲染截图。未产生时保持「待补」，严禁编造。
3. 记录本次编译/静态检查/浏览器验证的真实结果及环境。保存相关图片到 docs/evidence/。
4. 追加报告修订日志、当前问题和下一步计划，保持 PROGRESS.md 与报告一致。
5. PDF/PPT 根据主稿生成并检查版式与链接；没有用户要求导出时不必提前制作虚假的最终成品。
