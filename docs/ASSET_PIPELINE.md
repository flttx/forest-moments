# 模型与资产生产规范 v0.1

## 目标
Lux3D 或其他经允许的建模服务生成基础模型，Blender 统一模型结构、比例、UV、拓扑、骨骼和动作，输出可在浏览器稳定运行的优化 GLB。资产允许自制替换，不锁定单一 AI 供应商。

2026-10-24 用户修订：体积预算仅为可调整的参考指标。保留画面与动作，依据实际加载、内存和渲染测量决定优化；原固定下载数字不作为玩法推进或模型采用的硬门槛。


## Aholo 黑客松强制 Lux3D 使用要求（2026-10-22 规则沟通）
用户提供的主办方英文回复表示：**使用官方 Lux3D API，通过 Codex 或 MCP 生成参赛核心 3D 资产符合强制使用 Lux3D 的要求，无须使用 Web Studio**。生成后可使用 Blender 优化，再接入 Three.js。原文与证据边界见 [赛事规则沟通记录](evidence/hackathon/2026-10-22-lux3d-api-rule-confirmation.md)。

- 必须真实使用官方 Lux3D 生成核心 3D 资产；其他模型服务和 Blender 只能辅助，不能单独替代此赛事强制要求。
- 每件核心模型保留任务 ID、端点区域、模型操作名、脱敏请求参数、原始模型、Blender 优化结果、最终 GLB 和实际游戏截图，提交报告要清楚说明 Lux3D 的作用。
- **工具使用资格不等于商业使用授权**。模型的授权及第三方资源仍需独立核查。
- 当前只保存用户提供的文字转录，并未取得原始 Discord 消息链接或截图，也未因此新增任何 Lux3D 模型。
## 每件资产必须留存
资产 ID / 用途 / 生成服务与账户类型 / 创建日期 / 输入参考 / 模型原版 / 修整版 / 最终 GLB / 生成积分消耗（如有） / 授权依据 / 三角形数 / 贴图尺寸 / GLB 大小 / 动作骨骼验证 / 视觉对比截图 / 浏览器加载证据。

## 核心资产
- 浣熊：简单圆润比例，保留清楚的面部和自然下垂的环纹尾巴。动作要求走、跑、坐、蹲、钓鱼、划桨，尾巴独立控制并带阻尼。动画采用稳定骨架、根骨固定、脚步防滑、适配过渡。
- 工坊、瞭望台、围栏、路灯、船、钓具、树、岩石：同一低到中面数的风格；植物重复项做实例化。
- 池塘鱼和动物：少量种类和可见动作，优先局部精修。

## 资产门禁
1. 是否应在 Blender 中制作/优化？几何占位不视为交付模型。
2. 来源及商业使用权是否合法明确？尤其活动赠送积分生成物不可默认可商用。
3. Blender 验证法线、UV、原点、轴、尺度、碰撞代理、骨骼权重与动作。
4. 导出 GLB（需要时 Meshopt/纹理压缩），验证贴图大小、总包体积、浏览器渲染。
5. 多视角截图验收角色动作自然度、尾巴节奏、树木遮挡与建筑比例。
6. 记录优化前后数量和图像对比到 docs/evidence/。

## 初版预算（目标，非当前实测）
初次下载尽量 ≤ 15 MiB；场景 + 交互资产完整下载尽量 ≤ 25 MiB；树石尽量实例化。根据目标机器、实际视觉质量和比赛时限调整。任何超出需给出合理理由与测量。
