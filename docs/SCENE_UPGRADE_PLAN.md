## 1. 目标与实施边界

1. 使用 my-blog 已有生产树木和灌木网格、贴图，替换当前程序圆锥枝簇；保持源资产的造型和材质特征。
2. 迁移其草丛、花簇、颜色层次、风动及角色拨草表现，适配森林拾光现有地形与碰撞。
3. 使用其木质悬挂路灯及发光遮罩，替换当前圆柱加发光球占位，形成白天克制、黄昏/夜间温暖的道路照明。
4. 扩大小岛及实际可行走区域，使外圈树林、草地和步道有足够空间，形成疏密分区。

保留当前浣熊、衣服、尾巴、全部原动作、工坊、木塔、池塘、码头及船的相对关系。保留钓鱼/划船/鱼簿/种树存档契约；不把模型整体同比放大。本轮不扩展牧场玩法、工坊制作、完整昼夜循环、海浪物理或海岸游泳。

my-blog 作为只读来源，所有派生输出写入 forest-moments。复用不是重新生成，不调用付费服务，不把原 Tripo/Blender 资产登记为新 Lux3D 产物。没有提交、推送、上传或部署步骤。

## 3. 扩建尺度与空间安排

以下保留实施前参数与本轮采用的目标。2026-10-24 已应用目标尺寸；实际水线和净可走面积仍按下表说明理解。

| 项目 | 实施前基线 | 本轮采用值 |
| --- | --- | --- |
| 岸线半径参数中心值 | 20.8 m，加不规则偏移 | 约 29 m，约放大 1.4 倍 |
| 岛形直径参数 | 约 41.6 m | 约 58 m；实际水线随缓坡及岸线变化 |
| 可行走外圈半径上限 | 16.4 m | 约 23 m；实际可走范围扣除水/建筑/树干等障碍 |
| 圆形上限包围面积 | 约 845 m² | 约 1,662 m²，约 1.97 倍；不是净可行走面积 |
| 地形网格覆盖 | 50×50 m | 约 72×72 m，覆盖岸坡及水下边缘 |

空间安排：

- 中心生活区保留：出生点、工坊、木塔、牧场、种植点位置先不动，现有路径连接继续可用。
- 池塘、钓点、码头、船停泊点和划船边界不放大、不平移，避免破坏接触关系及已有交互。
- 外圈新增林间漫步区与草甸，外围针叶林成组布置，间隔开放林窗；少量阔叶树用于草甸和路口，不排成均匀圆环。
- 保留至少两处向海视线开口，避免新树把天空、海岸和地标完全封死。
- 补可连通的外圈步道及返回生活区的支路；不是把原道路和装饰整体缩放。道路净宽暂定 1.8–2.4 m，路边植被渐疏、草叶渐短。
- 树高按原资产比例与角色/建筑校准：普通树以约 4–7 m 起步，较高松树少量用于远侧轮廓；具体高度在单体对照后锁定。不得因树太大再缩小角色或建筑。

扩建必须统一修改 `terrain.ts` 的岸线/陆地范围、`IslandTerrain.tsx` 网格与材质、`Atmosphere.tsx` 海水深浅/碎浪边界、`movement.ts` 可行走边界、树干碰撞、道路与草地分布、相机及阴影覆盖。当前 CPU 与 GLSL 存在重复常量，先提取共享岛形参数，避免视觉陆地与碰撞/浅水线不一致。

## 4. 植被和路灯的接入要求

### 树木与灌木

- 从生产包提取选定模板，剥离原地图的实例变换，保留几何/材质；不直接摆入整套 my-blog 岛屿植被。
- 在本项目独立资产目录保存可追溯派生包。通过现有 Three.js 加载器和 InstancedMesh 复用网格/贴图；必要的整理、导出使用本地 Blender，不再重画树木。
- 生成固定种子的本岛布局清单，渲染与碰撞共用实例变换。树干碰撞使用生产模板的局部碰撞信息或实际树干底部范围校准，不能沿用原圆锥树的 `.25 * scale` 假设。
- 在出生点、建筑入口、池塘钓点、码头、种植点、道路和相机关键视线附近留空。避开水面、岸坡及建筑占地，检查树根接地与树冠穿屋。
- 保留自然比例差异和轻微叶色变化；先以约 60–90 棵树、30–50 丛灌木试排，数量为布局目标，不是验收成果。最终按画面疏密及实测性能调整。
- 遮挡问题先调整布置，再用局部淡出兜底；不让淡出成为全屏网点、灰色树冠或持续透明。

### 小草与小花

- 使用 my-blog 的多段弯曲草叶、双花头、根深梢浅的材质层次，替换目前的三角短草。
- 采用区域权重和花丛分布，林下短而疏、草甸较密、花朵聚成小片。保留原方案的暖黄、灰紫、柔粉色系，避免均匀撒点和高饱和色块。
- 当前岛面为程序材质，没有 my-blog 的地表颜色贴图和 GroundMask。适配共享地表颜色/道路权重采样；草根颜色与本岛地面一致，不照搬旧岛纹理坐标，也不为迁移草花引入整个旧 CollisionWorld/牧场系统。
- 对道路、水面、建筑、树干、码头、钓点、上下船点和种植点做排除或压低；角色经过时拨开，减少动态效果时关闭风动。
- 采用空间分块、按距离渐隐和按需建立实例，扩大面积后不一次性生成无限草量；实际草/花数量由掩码和帧预算决定。

### 路灯

- 使用 `Eco_lantern` 的完整木柱、悬臂、灯笼和原材质，替换当前 3 根球灯占位。
- 生活区入口与路口优先放置，新增外圈步道稀疏补灯，约 8–12 盏作为试排起点，平均间距约 10–14 m；按路段长度调整，不为凑数放灯。
- 灯柱避开通行带、树干和建筑；按实际柱脚建立碰撞，灯罩光源锚点从网格/遮罩校准，不凭模型中心猜测。
- 发光遮罩只点亮灯罩，白天弱或关闭、黄昏渐亮、夜间琥珀色；对接已有三时段预设，不扩展完整昼夜系统。
- 所有灯具可显示发光，但真实局部光源仅使用最多 4 个邻近池化点光，不为每盏灯增加阴影贴图。测试角色行走时的光源接替，避免跳亮及地面大片过曝。
