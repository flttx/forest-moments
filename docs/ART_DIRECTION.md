# 美术方向：温暖童话森林

视觉关键词：warm / cozy / storybook / handcrafted / forest / mature stylized / peaceful。

参考基线：E:\Projects\my-blog 的 Flttxq Forest Style v1（只读参考；不复制其具体资产或构图）。森林拾光独立设计，更强调休闲生活。

## 色彩与形体
- 深绿松叶 #28453A、中绿 #446B4F、草地 #879A68。
- 木结构 #8A5B3D、暗木 #4A3228；暖灰石 #7D7A6E；克制的屋顶暗灰 #3F3A3A。
- 窗灯/路灯琥珀 #D6934F，夕阳的金黄做局部焦点。
- 柔和、略不对称、手工切削感的 stylized 几何。少量细节提升质感，避免廉价低面塑料感。
- 松树为主，少量圆润阔叶、开阔草地、斑驳土路，地标靠地形/轮廓区分。
- 配置可读的中远近景、池塘反光、随风摆动、柔和雾；保持晴日与日落视觉一致性。

## 不采用
写实摄影风、Voxel、浓艳儿童玩具感、暗黑奇幻、赛博朋克、大型城堡或大量精雕建筑。不是要完全临摹 Bruno Simon 的具体场景。

## 视觉 Gate
A 方向板/色彩/建筑轮廓 → 用户确认；
B 小岛地形/主路/地标位置 → 浏览器可行走评估；
C 角色、树木、工坊、牧场、瞭望台、池塘、木船资产 → 动画/比例/细节复核；
D 最终昼/夕/夜多机位实机截图与性能验证。
每个 Gate 保留实际产物和前后对比；禁止以旧截图替代新版本验收。
