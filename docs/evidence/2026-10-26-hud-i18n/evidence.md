# 界面隐藏、中英切换与界面风格精修（2026-10-26）

状态：**已实现，本机限定验证，待用户查看**。

## 需求

- 界面增加隐藏入口（用户选：全部隐藏、只留一个小按钮，H 键切换；错误提示和进行中玩法的卡片保留）。
- 增加语言切换，暂为中英文（用户选：默认中文，菜单加“中 / EN”，选择记在本机）。
- 界面交互风格优化（用户选：交互反馈、视觉层级与排版、整体更精致，保留纸感方向）。用户补充：标题“森林拾光”用特殊字体，不需要每个元素都加背景框和圆角。

## 实现

### 语言

- `src/i18n.ts`：228 条文案，中文为源语言，英文用 `Record<Key,string>` 约束，漏译在类型检查时报错。`t(key, 参数)` 读取当前语言；`useT()` 让组件随语言重绘。切换时同步 `<html lang>` 与页面标题，选择存在 `forest-moments:lang:v1`，存储被禁时仅本次会话有效。
- 提示、地点、帮助、按钮、面板、加载与错误界面都在渲染时翻译，切换后立即生效。钓鱼失败原因、木工反馈在状态里改存原因代码（`FishingReason`、`CraftFeedback`），显示时翻译。地点名称/提示、成长阶段名从数据文件移到词典，按 id 取。
- 已知边界：store 写入的单条通知按写入时的语言生成，切换语言那一刻已显示的通知保持原语言，直到消失或关闭。
- 中文值与原文案逐字一致，现有单测和 55 个浏览器脚本中的中文断言不受影响。

### 隐藏界面

- 工具条最右的隐藏按钮或 H 键（忽略长按重复、组合键与输入框）进入“照片视角”：标题、工具条、底部提示、引导全部收起，右上角只留半透明恢复按钮；错误通知、钓鱼/木工卡片、塔上观景、睡眠与鱼缸照常显示，避免玩到一半看不到进度。隐藏时会关闭已打开的面板并恢复游戏。不跨刷新记忆，新访客不会进来就看不到界面。

### 风格

- 字体：霞鹜文楷 LXGW WenKai v1.530（SIL OFL 1.1；作者附加许可允许为网页分发做子集化/转 WOFF2 并沿用原名）。`scripts/build_ui_font.py` 从词典和界面源码提取 454 个实际用字加可打印 ASCII 与常用标点，生成 Regular/Medium 两个 WOFF2，各约 104 KB，`font-display: swap`。原始 TTF 只作子集源、不入库（Regular `2d73eea9…`、Medium `f4b8a34d…`）。许可文本随包发布在 `public/fonts/LXGW-WenKai-OFL.txt`。
- 标题“森林拾光 / Forest Moments”去掉背景框，用文楷直接写在场景上，奶白字配柔和投影，昼夜都可读。
- 右上原三个独立按钮框合成一条纸面工具条：地点 / 鱼簿 / 帮助（SVG 图标 + 文字）| 中 / EN | 隐藏。工具条内按钮不加框，悬停着色，按下下沉 1 px，选中项琥珀底加下划线，键盘焦点琥珀描边。窄屏（≤760 px）只显示图标，文字保留给读屏。
- 层级：可操作的（动作按钮、面板、玩法卡片、通知）用纸面；只读的状态、去向提示、首次引导、模式提示改为半透明墨色条。底部动作去掉“框里套框”，动作本身就是苔绿按钮。
- 图标：取自 Lucide（ISC），统一 1.75 线宽，替换 `×`、`←`、`→` 字符。错误通知去掉左侧色条，改为警示图标 + 错误色描边。
- 所有按钮补齐悬停/按下/禁用/焦点状态；只有小尺寸的颜色与位移过渡，不加任何浮层入场动画（此前已证实浮层动画会在 WebGL 画面上造成 140–210 ms 长帧）；减少动态效果时全部关闭。主题化了选中文字颜色和面板滚动条。

## 过程中的调整

| 发现 | 处理 |
| --- | --- |
| 文楷的“…”是中文居中省略号，英文里显示成“Casting···”（`iterations/1-cjk-ellipsis-in-english.png`） | 英文时用同一字体文件的另一个 `@font-face`，`unicode-range` 排除 U+2026，省略号由系统字体在基线上显示 |
| 引导条里“右键”“滚轮”挤在 12 px 键帽里 | 键帽字号 12→13 px、加宽内边距 |
| 旧 UI 回归的布局扫描在 1024×768 发现工具条与居中引导条重叠（工具条比原三个按钮宽） | 宽度 ≤1320 px 时引导条移到工具条下方 |
| 本机 pip 一度无法安装 brotli，先出了 WOFF 版（约 252 KB） | brotli 装上后改为 WOFF2（约 208 KB），删除 WOFF |
| 确认轮第一次运行在首次加载时超时 | 单独截图确认页面正常（样式改动后 Vite 首次重编译、本机负载高），重跑通过 |
