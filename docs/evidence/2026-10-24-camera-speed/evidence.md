# 第三人称镜头转向节奏 · 2026-10-24

已实现，本机限定验证通过。方向/掉头与连续四方向/墙边两组最终检查共 60 张，全部通过且无控制台异常。

用户指出相机转动太快，追加要求参考动作游戏第三人称视角。参考 Epic 官方 [Spring Arm](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/Engine/USpringArmComponent) 的旋转滞后与碰撞收臂机制，自行实现移动意图确认与受限阻尼弹簧；未复制游戏素材或使用其专有参数。

- 持续真实位移方向确认 0.18 秒，6° 目标变化死区。点按短于确认时长不会接受新方位，撞墙时不累计确认时长。
- 弹簧系数 16、阻尼系数 8；角速度上限 90°/s、角加速度上限 360°/s²，最多 1/120 s 子步。进入其他空间时重置状态。
- 保留角色自身转向响应、世界方向按键、相机距离/FOV、位置跟随、碰撞盒收臂和近墙抬高；未实现鼠标自由环绕或完整动作游戏操控。
- 60/60 单测（15 文件）通过：包含点按不追转、微调死区、30/60/144 Hz、掉头速度/加速度、停步收敛、最短弧和无效帧时间。lint 无警告、build 成功，主 JS 1304.89 kB / gzip 368.90 kB，保留大包提示。

## 前后测量

改前通过基准（本地原始记录：`before-verified/headless-validation.json`）：白天、室内/室外、90°/180°，8 张。改后三时段（本地原始记录：`after/headless-validation.json`）：同样输入、三时段，24 张。每次先向北移动并稳定，再用真实方向按键转弯；开发 store 仅设置起始地点。记录逐帧方位、目标与相机坐标。

旧版白天反向输入后约 350 ms 已旋转 151–153°，改后全时段约 6.35–7.26°；新镜头完成 180° 转向的 95% 约 2.39–2.41 秒，90° 约 1.62–2.00 秒。时间含本机渲染/调度影响，不当作所有设备的精确时长；90°/s 和 360°/s² 约束的是跟随臂方位，不宣称碰撞避让后的最终视线角速度始终满足该值。

`before` 是初次基准脚本失败：+π / -π 表示同向却被严格相等判断拒绝。修复测试角差比较后另存 `before-verified`，没有覆盖失败。动态截图为早期/稳定后状态，截图调用存在调度延迟，不能当成严格逐毫秒同步对比；逐帧 JSON 为量化依据。

所有截图为本机 Edge 156.0.4314.42，1440×900。没有生成插画、模型或 Lux3D/Blender 产物，无新增付费 API 调用。近墙较陡俯视、细小物体遮挡仍为既有限制；未提交、推送或部署。
