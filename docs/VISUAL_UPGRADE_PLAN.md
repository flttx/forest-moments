## 2. 总体判断

单体模型（工坊、木塔、卧室小屋、码头、船、浣熊、松树）质量已经可用；画面不满意的主因不在单体，而在**光影、海面、地表与崖壁这些“铺满屏幕”的大面积元素**，以及它们之间的风格不统一。

1. **光照扁平，缺少明暗层次。** 半球补光 1.1、环境光 0.55，场景没有任何后期（无环境遮蔽、无泛光、无调色）。物体像“贴”在草地上，没有接触阴影；黄昏只是整体变暗，地面和树没有暖色主光；夜晚是暗绿色而不是蓝调，路灯光晕弱，工坊/小屋窗户不亮。见 `00-default-dusk`、`00-default-night`、`night-workshop`。
2. **海面重复纹理和灰色天际带。** 海面法线由固定频率正弦叠加、无距离衰减，远处形成明显的规则棋盘/摩尔纹，是全岛视角最刺眼的问题；雾色与天空地平线之间出现一条灰白带。见 `02-zoom-wide`、`day-fullIsland`、`night-fullIsland`。
3. **崖壁与溪口像“翻糖蛋糕”。** 高度场直接拉出大面积光滑竖墙，只靠低频程序着色，颜色偏米白、没有岩层和碎石，入海口出现两根光滑柱体；与 AHOLO 礁石的写实扫描质感、海边低多边形碎石三种风格并存。见 `day-seaCliff`、`day-creekMouth`、`day-reef`、`day-stream`。
4. **地表单调、草叶呈“撒点”。** 底色几乎是一种绿，草丛均匀点状分布、露出平涂底色；营地等空地大片裸绿；小路近看发糊，碎石是平面着色的白色多边形；沙滩与草地交界生硬，沙滩无湿沙带和潮线细节。见 `day-player`、`day-camp`、`day-beach`。
5. **构图与疏密缺少节奏。** 全岛俯视时树木均匀铺满，没有明显林窗、草甸和视线廊道；岛形是“圆饼”轮廓。阔叶树近景是低多边形色块。池塘是一块光滑镜面加深色描边，缺少芦苇、石块、浮叶等岸边生命。见 `day-fullIsland`、`day-farm`、`day-pond`。
6. **默认镜头偏高偏陡。** 开局镜头几乎俯视地面，看不到天空和海平线，树冠被画面上沿切掉，“海岛森林”的第一印象没有建立。见 `00-default-hud`。（初稿“6 次滚轮即到全岛、缺少中景”系每次 deltaY 300 的测试事件所致，按普通鼠标每格 100 实测约 18 格才到全岛，中间有完整中景；真正的中景问题是第 5–7 格附近镜头会进入阔叶树冠，见 V1 证据。）
7. **界面遮挡（已有 UI 方案覆盖）。** 大标题卡、常驻地图、底部键位条和原型角标同时占据四角，与 UI 方案判断一致。

## 3. 视觉目标

保持 [美术方向](ART_DIRECTION.md)：成熟克制的温暖童话森林。具体落到可检查的画面目标：

- **层次**：近景暗、中景亮、远景被雾和天空吞没；树根、建筑基座、栅栏脚有可见接触阴影。
- **时段辨识度**：白天清透暖白；黄昏低角度琥珀主光、长阴影、天空与海面金色反光；夜晚蓝灰月光为主，琥珀灯光和窗光成为焦点，不是“调暗的白天”。
- **大面积材质**：海面远处平静柔和、近岸有浪花与浅水渐变；崖壁有分层岩体与苔藓；地表有色斑、落叶/松针与疏密草甸。
- **风格统一**：所有岩石、碎石、礁石统一为圆润的手作风格与暖灰岩石色（#7D7A6E 系），不混用平面低多边形与写实扫描。
- **构图**：开局镜头同时看到浣熊、近景路径、林间地标和一线天空/海；全岛视角有 2–3 处林窗、草甸和清晰岸线轮廓。

## 4. 阶段计划

按“单位工作量带来的画面提升”排序。每阶段独立可回退，完成后用基线机位复拍对比，再进入下一阶段。

### V1 光照与后期（已实现，本机限定验证，2026-10-25）

- 重新平衡三时段：降低半球补光与环境光，提升主光对比；黄昏改为低角度琥珀主光、拉长阴影；夜晚改为冷蓝月光为主，压低草地亮度与饱和度。
- 后期链：环境遮蔽（接触阴影）、仅对灯罩/窗光/篝火的泛光、轻度调色与暗角，最后输出色彩空间。实现方式见决策 D1。
- 工坊、小屋窗户和灯笼使用随时段渐亮的发光材质；篝火未点燃时保留余烬微光。
- 提供画质档位：低档关闭环境遮蔽与泛光；“减少动态效果”下保持静态画面一致。
- **完成标准**：基线 22 机位复拍，夕/夜与白天一眼可辨；物体底部可见接触阴影；灯光无大面积过曝；P95 帧间隔与改动前实测对比（本次审查未测帧时间，V1 动工前先补测），并以约 22 ms 为参考线（非硬门槛，超出须给出原因与档位方案）。

### V2 海面与天际线（已实现，本机限定验证，2026-10-25）

- 海面法线改为多方向噪声波，并按相机距离衰减强度与频率，消除远处规则纹理；加入菲涅尔，使远海反射天空色、近海呈现浅水透明感。
- 雾色与天空地平线色统一取同一时段值，去掉灰白带；黄昏保留太阳在海面上的金色光路。
- 岸线浪花改为连续、随时间推进/退回的潮线，替代现在的虚线状白带；沙滩增加湿沙深色带。
- **完成标准**：`02-zoom-wide`、三时段 `fullIsland` 无可见重复纹理和天际灰带；`day-beach`、`day-dock` 潮线连续自然；划船、钓鱼等水面交互回归不变。

### V3 海岸与崖壁重做（已接入，本机限定验证，待用户查看；`day-reef` 坡道与路边碎石留待后续）

- 降低并打碎海崖竖墙：地形高度场只负责大形，崖面改由一组手作风格岩石模块（3–5 种可旋转复用的分层岩块）覆盖，底部堆碎石，顶部草皮包边。模块来源见决策 D3。
- 重做溪口与入海处：去掉两根光滑柱体，改为台阶状岩块与卵石滩。
- 统一全部岩石：海边圆石、路边碎石改为平滑法线和统一暖灰色；AHOLO 礁石调色/降低写实细节以匹配，或用新岩石模块替换。
- 沙滩与草地交界加入沙丘草、零星漂流木和贝壳点缀（少量、成组）。
- **完成标准**：`day-seaCliff`、`day-creekMouth`、`day-reef`、`day-stream` 同机位复拍不再出现大面积光滑墙面；可行走高程、桥面、溪流碰撞和划船边界保持不变（回归现有扩岛导航检查）。

### V4 地表与植被构图

- 地表：大尺度色斑（林下偏暗偏冷、空地偏暖亮）、树下松针/落叶层、路边草皮翻边与车辙；近景小路提高细节频率，不再发糊。
- 草地：按区域分配密度——草甸连成片、林下稀疏、路边渐短，避免点状撒布露出底色；营地等空地补足草和小花。
- 构图：在全岛布局中留出 2–3 处林窗和一条看海视线廊道，林缘用灌木过渡；花丛成片集中在草甸和路口。只调实例布局与密度，不换树种。
- 阔叶树近景叶片修整（近距离 LOD 或材质），避免低多边形色块感。
- **完成标准**：`00-default-*`、`day-player`、`day-camp`、`day-fullIsland` 复拍无明显露底撒点；全岛可辨认林窗与草甸；草地实例数与帧时间变化记录在案。

### V5 地标点缀与生活感

- 池塘：岸边芦苇、浮叶、石块、由浅到深的水色和岸边湿土渐变；保留钓点通道。
- 牧场、工坊、营地：地面踩踏土斑、干草、木料堆，建筑基座与地面的过渡。
- 环境生命（均受“减少动态效果”控制）：白天蝴蝶/飞鸟、黄昏飘絮、夜晚萤火虫；树木轻微风动沿用现有机制。
- **完成标准**：`day-pond`、`dusk-pond`、`day-farm`、`night-camp` 复拍；钓鱼、喂养、坐下、篝火交互回归通过；不遮挡交互点。

### V6 默认镜头与中景（开局镜头随 V1 实现；中景档经实测不需要；树冠遮挡按用户选择“自动拉近”随 V2 实现）

- 开局与步行默认镜头适当降低俯角、略微靠近，让画面上缘出现天空/海平线；滚轮增加中景档位，近景→中景→全岛过渡更平缓。
- 不改变已确认的操作规则：WASD 相对镜头、右键环绕/俯仰、滚轮缩放、Q/E、不自动追转，以及各交互专用机位。
- **完成标准**：`00-default-hud` 同时可见角色、路径、树冠全貌与天空；现有镜头单测和轨迹检查（近墙保护、远景限制）全部通过。

## 5. 与 UI 方案的关系与排期

- UI 方案（U 轨道）内容不变：轻手绘纸感、首次引导＋按需提示、菜单暂停。它减少画面遮挡，与场景升级互补。
- 已确认顺序：**V1（含 V6 镜头）→ V2 → U → V3 → V4 → V5**。理由：V1/V2 改动集中、收益最大，先确定新的光照与色调，U 的纸面配色再据此校准对比度；V3–V5 涉及模型与布局，工作量最大，放在后面逐个复核。
- 补充两条 UI 观察，实施 U 时一并核对：纸面面板在新的夜晚色调下的对比度；全岛远景下仅保留最小入口。

## 7. 验证与交付（每阶段执行）

- `node scripts/check_visual_review.mjs <输出目录>` 复拍全部机位，与 [基线](evidence/2026-10-25-visual-review/baseline/) 同名图对比；对比结论和失败项写入 `docs/evidence/` 对应阶段目录，不以旧图冒充新图。
- 1920×1080、1280×720、1024×768 抽查；记录 30 秒固定机位与移动路线的平均/P95 帧间隔、draw calls 和三角面，和改动前对比。
- `pnpm lint`、`pnpm test`、`pnpm build`；涉及地形、岩石碰撞、镜头的改动跑现有扩岛导航、镜头、划船与钓鱼回归脚本。
- 同步更新 PROGRESS.md、PRD 与项目报告：明确每项是计划、实现待验证还是已验证。
- 不部署、不推送、不调用付费资源（D3 已确定本地 Blender）；新增模型先核对使用权并记录来源与制作过程。
