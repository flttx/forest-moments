# 坡地跟随镜头 · 证据（2026-10-28）

- 改动：户外步行时，相机按视线方向前后 1.4 m 的地面高差计算坡度，上坡时降低俯角（最多 0.16 rad），下坡时抬高俯角（最多 0.20 rad），按约 0.4 s 时间常数平滑；拉远到全岛视角时逐渐取消；室内、划船、钓鱼不受影响。代码：`src/game/followCamera.ts` 的 `slopePitch`，`src/world/ForestWorld.tsx` 步行镜头分支。
- 脚本：`scripts/check_slope_camera.mjs`（隔离无头 Edge，1440×900，`FOREST_SLOPE_STAGE=before|after`）。在页面内按当前镜头朝向搜索最陡的上坡、下坡可行走点，放下浣熊静置 2.5 s 截图，再按住 W 走 0.9 s 截图。
- 结果（镜头实际俯角，orbit 设定 0.31 rad）：

| 场景 | 改动前 `before/` | 改动后 `after/` |
| --- | --- | --- |
| 平地 (0,0) | 0.310 | 0.311 |
| 上坡 (-11.5,-18) | 0.310 | 0.175 |
| 下坡 (-4,-11) | 0.318 | 0.509 |

- 截图复核：改动前下坡静置时相机陷进身后坡面的草丛，看不到浣熊（`before/downhill-still.png`）；改动后俯视可见浣熊和坡下小路（`after/downhill-still.png`）。上坡视线放平，能看到坡顶之外的林线和海面（`after/uphill-walking.png`）。
- 限制：只做了无头截图，未人工试玩；下坡截图左侧仍有一棵阔叶树冠挡住部分画面，属于既有树冠避让范围（只处理包住相机的树冠），本轮未改。
