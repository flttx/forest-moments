# 森林拾光 Forest Moments · 产品需求文档 v0.2

更新：2026-10-24｜状态：持续修订的需求，实际实现以 PROJECT_REPORT 为准｜类型：PC 浏览器 3D 休闲生活微型世界

## 1. 主题与愿景
森间拾光：海上一座会慢慢生长的童话森林小岛。周围大海、自然海岸与岛内独立淡水池塘共同构成场景。以小而精的地图、手绘感风格和可互动的慢生活为核心。玩家操作浣熊，3–5 分钟能触达核心地标，但能通过日常互动留下痕迹。拒绝大型开放世界、复杂数值经营和堆叠建筑。

## 2. 目标用户与体验
2026-10-24 最新操作要求：WASD 与鼠标视角参考本机 my-blog。方向键每帧相对独立的镜头水平朝向移动，角色朝向实际位移；鼠标右键拖动自由环绕/俯仰、滚轮缩放、Q/E 环绕，按住 W 时转动镜头可以连续转弯。步行镜头不自动追转，以避免与玩家自由视角和侧向移动相互干扰；保留近墙保护、平滑转身及专用交互机位。船上允许鼠标环绕并延时回到船后，塔上支持右键环顾。这条新要求替代此前无手动镜头时的方向后随及 v0.43 的最新角色朝向输入规则。
面向希望短暂放松、喜欢自然与可爱角色、愿意探索小世界的 PC 玩家。典型体验：林间漫步 → 发现工坊/牧场/池塘 → 种树 → 钓鱼 → 划独木舟 → 黄昏登塔观景。

## 3. 地标
- 工坊：从正门进入可行走的室内，在木工台完成材料→制作→可见物品，再返回小岛。当前最小配方为修整旧木墩凳；配方扩展和经营仍为后续目标。
- 路灯：木灯柱，夜幕下温暖的琥珀光。
- 树木：环境以松树为主，少量阔叶，路径两侧疏密分区；种植采用同种阔叶树四阶段：单茎未分叉小苗 0.22 m → 分叉树苗 0.55 m → 幼树 1.5 m → 成树 3 m。已实现一次栽种、观察、45/120/240 秒真实时间成长与跨刷新状态，本机限定验证见报告 5.28；暂不含浇水、采收或多地块经营。
- 养殖场：小围栏和几只动物，喂养/巡游反馈。当前一鸡一羊、鸡舍/食槽/水槽已接入，F 添料、到槽进食、食物减少与完成次数存档已实现并完成本机限定验证；尚无繁殖、采蛋、剪毛或经营库存，见报告 5.30。
- 瞭望塔：低体量开放式木塔，底部不设封闭石砌房间；已接入楼梯脚触发的第一人称观景、环顾/俯仰和返回原位，当前验证见报告 5.32。逐级爬楼、平台自由行走与攀爬动画待制作。
- 池塘：岛内淡水钓点，保留钓鱼与鱼簿闭环。
- 海边码头：东岸沙滩通向木栈桥，在海中划船；最远航行范围沿实际小岛岸线设置，支持返回停靠和下船。已加入上下船短遮罩镜头过渡、轻微船体起伏、原桨触水涟漪和按距离产生的尾流；专用跨舷动作与浮力物理仍待制作。
- 工坊与瞭望塔分布在岛的不同方向；当前布局分别采用西南与东北，道路与植被为入口和视线留空。
尽量不要再增加大量房屋。鸟瞰清楚，近景有层次。

## 5. 非功能约束
- 2026-10-24 按用户最新要求，体积预算改为可调整的参考指标，不作为玩法推进的硬门槛。优先保证画面、动作与实际加载体验；用真实下载耗时、内存和跨设备表现决定优化，避免为固定数字损伤资产。上一阶段模型/轨迹/植被 51.82 MiB，较此前减少 47.73%，详见报告 5.31；原完整下载 25 MiB / 首屏 15 MiB 仅保留为历史估算。
- Windows / PC 的现代 Chromium 浏览器优先；移动端后续再适配，不能把当前小屏 UI 等同完整触屏控制。
- 纯前端 Vite Static 版本，存档优先 localStorage，不依赖 Next.js 服务端。
- 重复树石优先 Instancing；GLB 和贴图优化后才发布；建立真实浏览器性能基线再锁定 FPS。
- 输入、UI、键盘焦点、减少动画设置和无 WebGL 时降级要逐步补齐。
- 第三方模型来源和商业授权必须逐项记录，活动赠送积分生成的模型也不可默认认为可商用。

## 6. 交付阶段
P0 项目初始化和灰盒；P1 风格与地图；P2 浣熊模型/自然动作；P3 种树和钓鱼；P4 船、动物、工坊、观景；P5 质感、音画、性能；P6 国际站发布与报告终版。

## 7. 非目标
不制作多人生存、大型经营、复杂战斗、大地图无缝探索、博客 CMS 或云端账号系统。
