## 1. 主题与愿景
森间拾光：海上一座会慢慢生长的童话森林小岛。周围大海、自然海岸与岛内独立淡水池塘共同构成场景。以小而精的地图、手绘感风格和可互动的慢生活为核心。玩家操作浣熊，3–5 分钟能触达核心地标，但能通过日常互动留下痕迹。拒绝大型开放世界、复杂数值经营和堆叠建筑。

## 2. 目标用户与体验
2026-10-29 拍照修订：所有滤镜与相框默认开放，不再要求手账完成页数；低画质关闭景深的性能保护保留。此要求覆盖历史滤镜解锁方案。

2026-10-29 群岛实施 v6（**主岛西扩及雾松岛首版已实现，另两岛仍为计划**）：用户明确保留主岛西扩，另外增加三座较小邻岛。以扩建前主岛可行走面积为基准，雾松岛、秋岚岛各 20%–25%，潮汐岛 12%–18%；邻岛由海水分开，不与西扩混为同一地块。西扩已有地形与环线；湿地已替换为不规则浅水、闭合泥岸与岸边水草，栈道采用 Blender 自制木板/梁柱模块，保留原生活区与旧档；湿地补岸后实际可站立面积约 +37.0%，略低于原 +40%–60% 目标。古松、云杉已按单体参考经 AHOLO API 生成并接入，白桦、枫树、赤杨和海风松仍待制作。模型默认保留完整几何，只整理尺寸、原点和材质；减面必须有实测瓶颈和视觉对照依据。秋岚岛跟随季节换叶色，潮汐岛首版为固定浅池；雾松岛加入倒木与林缘灌木后可站立面积 853.5 m²，为原主岛的 23.10%；已接入多泊位、古松发现、到访记录和安全泊位刷新恢复，单段航行 30–50 秒是验收目标，实际测量见证据。首版独立蕨丛、局部岩脊、不规则岸湾与柔边薄雾已接入，倒木与林缘已细化，完整岩岸仍待补齐；后续再依次扩展另外两岛。详见[群岛方案](ISLAND_EXPANSION_PLAN.md)、[邻岛图册](ISLAND_NEIGHBOR_REFERENCES.md)与[主岛证据](evidence/2026-10-29-west-expansion/evidence.md)与[雾松岛倒木与林缘证据](evidence/2026-10-29-mist-logs/evidence.md)。

2026-10-24 最新操作要求：WASD 与鼠标视角参考本机 my-blog。方向键每帧相对独立的镜头水平朝向移动，角色朝向实际位移；鼠标右键拖动自由环绕/俯仰、滚轮缩放、Q/E 环绕，按住 W 时转动镜头可以连续转弯。步行镜头不自动追转，以避免与玩家自由视角和侧向移动相互干扰；保留近墙保护、平滑转身及专用交互机位。船上允许鼠标环绕并延时回到船后，塔上支持右键环顾。这条新要求替代此前无手动镜头时的方向后随及 v0.43 的最新角色朝向输入规则。
面向希望短暂放松、喜欢自然与可爱角色、愿意探索小世界的 PC 玩家。典型体验：林间漫步 → 发现工坊/牧场/池塘 → 种树 → 钓鱼 → 划独木舟 → 黄昏登塔观景。

## 2026-10-25 追加需求（首版已实施，细节见报告 5.43）

扩岛应包含可行走起伏、高地、溪谷/木桥、宽沙滩、悬崖/礁石与海边观赏点；先以整体概念 v3 讨论空间和高程，不把半径扩张与一条溪流当作完整方案。新增可进入卧室、床上睡觉、养实际渔获的鱼缸，以及可点燃/熄灭的篝火营地与休息座位。工坊增加专用工具动作、手部接触和成品坐凳。精细新模型经用户授权使用 AHOLO；椅子复用 my-blog 已适配模型与动作，鱼缸参考该项目。用户确认开始后，上述最小闭环已接入并完成本机功能验证，实际状态见报告 5.43。鱼缸按后续反馈缩为 72%；座椅仍用 my-blog 原模型。最新休息流程见下段；木工衣袖形变及养鱼经营仍是后续工作。

2026-10-25 休息交互修订（已实现并完成本机限定验证，报告 5.44）：不制作上下床动画，也不保留原整体侧卧。点击床边“上床休息”或按 F 后，切换固定的全岛俯瞰镜头；按小岛当前昼夜状态，白天/黄昏观赏日落到夜晚，夜晚观赏日出到白天。太阳高度、晨昏天空、海面、月光及路灯随进度连续变化。约 18 秒后回到卧室床边，恢复操作并保存目标时段；F、Esc 或按钮可跳过过渡。当前不绑定电脑实时时钟，也不承诺全天自动流逝系统。

2026-10-25 画面细化（报告 5.45）：溪口融入海面、源头收圆、崖壁改为不规则矿物纹理，沿岸小石落到潮线。原通行高程和桥面保持，尚无侵蚀或水流物理模拟。

2026-10-25 滚轮范围修订（报告 5.46）：室外可连续拉远至完整小岛与海岸线，远景逐渐转为岛心构图并限制过低俯角，仍可鼠标环绕；远景收起顶部介绍和地图，拉近恢复。室内保留原缩放范围，交互专用镜头沿用既有规则。

2026-10-25 树木显示修订（报告 5.47）：浣熊靠近树木时整棵树保持可见，不因相机视线消隐；树干实体碰撞继续保留，叶色、阴影与远近模型切换保留。允许真实树冠遮挡视线，树冠相机避让尚未实现。

2026-10-25 整体 UI 升级（已实施并完成本机限定验证，用户查看通过，见报告 5.52）：已确认轻手绘纸感、首次引导＋按需提示；地点、鱼簿与帮助按需展开，打开面板暂停角色操作和玩法计时，关闭后继续。统一精简主界面、玩法提示、通知及加载/错误界面，保留必要状态与操作反馈。完整规格和验收要求见 [UI 升级方案](UI_UPGRADE_PLAN.md)。本次仅归档方案，不代表界面已升级。

## 3. 地标
2026-10-26 篝火视觉修订（已实现，本机限定验证，待用户查看，报告 5.63）：参考本机 my-blog，用持续变形的柔软火焰、上升渐隐火星和轻微变化的暖光替换硬边几何火苗；保留原点燃/熄灭、座椅和连续烤火手账闭环，减少动态效果时静止火焰、关闭火星并固定照明。采用风格化着色器效果，不承诺体积燃烧模拟。

- 工坊：从正门进入可行走的室内，在木工台完成材料→制作→可见物品，再返回小岛。当前最小配方为修整旧木墩凳；配方扩展和经营仍为后续目标。
- 路灯：木灯柱，夜幕下温暖的琥珀光。
- 树木：环境以松树为主，少量阔叶，路径两侧疏密分区；种植采用同种阔叶树四阶段：单茎未分叉小苗 0.22 m → 分叉树苗 0.55 m → 幼树 1.5 m → 成树 3 m。已实现一次栽种、观察、45/120/240 秒真实时间成长与跨刷新状态，本机限定验证见报告 5.28；暂不含浇水、采收或多地块经营。
- 养殖场：小围栏和几只动物，喂养/巡游反馈。当前一鸡一羊、鸡舍/食槽/水槽已接入，F 添料、到槽进食、食物减少与完成次数存档已实现并完成本机限定验证；尚无繁殖、采蛋、剪毛或经营库存，见报告 5.30。
- 瞭望塔：低体量开放式木塔，底部不设封闭石砌房间；已接入楼梯脚触发的第一人称观景、环顾/俯仰和返回原位，当前验证见报告 5.32。逐级爬楼、平台自由行走与攀爬动画待制作。
- 池塘：岛内淡水钓点，保留钓鱼与鱼簿闭环。
- 海边码头：东岸沙滩通向木栈桥，在海中划船；最远航行范围沿实际小岛岸线设置，支持返回停靠和下船。已加入上下船短遮罩镜头过渡、轻微船体起伏、原桨触水涟漪和按距离产生的尾流；专用跨舷动作与浮力物理仍待制作。
- 工坊与瞭望塔分布在岛的不同方向；当前布局分别采用西南与东北，道路与植被为入口和视线留空。
尽量不要再增加大量房屋。鸟瞰清楚，近景有层次。

## 5. 非功能约束
- 2026-10-24 按用户最新要求，体积预算改为可调整的参考指标，不作为玩法推进的硬门槛。优先保证画面、动作与实际加载体验；用真实下载耗时、内存和跨设备表现决定优化，避免为固定数字损伤资产。上一阶段模型/轨迹/植被 51.82 MiB，较此前减少 47.73%，详见报告 5.31；原完整下载 25 MiB / 首屏 15 MiB 仅保留为历史估算。
- 2026-10-26 用户明确范围：仅支持 PC 浏览器的键盘与鼠标操作，不兼容手机界面，不开发移动端布局或触屏控制，也不列为后续适配目标。1920×1080、1280×720、1024×768 是 PC 窗口验收尺寸；手机宽度溢出不作为发布阻塞项。
- 纯前端 Vite Static 版本，存档优先 localStorage，不依赖 Next.js 服务端。
- 重复树石优先 Instancing；GLB 和贴图优化后才发布；建立真实浏览器性能基线再锁定 FPS。
- 输入、UI、键盘焦点、减少动画设置和无 WebGL 时降级要逐步补齐。
- 第三方模型来源和商业授权必须逐项记录，活动赠送积分生成的模型也不可默认认为可商用。
