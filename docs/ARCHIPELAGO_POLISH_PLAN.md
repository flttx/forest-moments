# 群岛整合与美术打磨计划

更新：2026-11-03｜状态：阶段 1、2 完成；阶段 3 进行中（3a–3c 已接入，3d/3e 实现待验证，3f 待做）｜发现记录：[ARCHIPELAGO_POLISH_FINDINGS.md](ARCHIPELAGO_POLISH_FINDINGS.md)｜会话日志：[PROGRESS.md](../PROGRESS.md)

## 目标

1. 让雾松、秋岚、潮汐三座小岛和主岛连成一个群岛世界，不再是几块各自独立的海中陆块。
2. 让每座小岛有值得停留的内容：轻玩法加布景，收获能带回主岛。
3. 完成美术清单：
   - 西林树冠挡镜头；
   - 树形重复、缺小树形态；
   - 连续礁岸；
   - 岸岩远看偏小、夜间对比偏低；
   - 潮汐贝壳；
   - 赤杨；
   - 主岛内陆起伏偏缓。

## 用户决定（2026-11-03）

| 问题 | 决定 |
|---|---|
| 参照 | 不必按概念图，按游戏本身需要设计 |
| 割裂感 | 四项都要处理：海上没有过渡、岛形规整像盖章、风格与主岛不统一、玩法与主岛脱节 |
| 岛上内容 | 轻玩法加布景：每岛 2–3 个小互动，可带回主岛；不加经营数值和新角色动作 |
| 赤杨 | 授权 AHOLO 生成（消耗积分），之后在 Blender 整理并接入 |
| 顺序 | 先做群岛，再做美术清单 |

## 约束

- 仅 PC 浏览器。纯前端静态。
- 旧存档必须兼容。新增存档字段要能缺省解码。
- 泊位坐标、往返流程、刷新回到安全泊位不变。
- 小岛面积比例保持：雾松、秋岚各为原主岛的 20%–25%，潮汐为 12%–18%。
- 重塑岛形会改变邻岛逐坐标基线（tideCoast、autumnTravel、autumnUnderstory 等）。用户选择了“岛形规整”这一项，视为同意更新邻岛基线；更新时在证据中记录前后差异。
- 岛形函数的 TS 与 GLSL 两份必须同步：海面浅水、泡沫与岛地形共用同一条边界。
- 每阶段都要过 lint、test、build，并采集实机静音截图。改到玩法时，跑相应的真实键鼠检查。

### 阶段 1：海上过渡 `complete`（2026-11-03，[证据](evidence/2026-11-03-archipelago/evidence.md#阶段-1海上过渡)）

- 岛间浅水沙脊：海面浅色带沿主岛东岸→雾松→秋岚→潮汐连成断续的浅滩，不形成陆桥。
- 露出水面的小礁与海蚀柱：复用海岸套件，成簇分布在航线两侧，不进入可航行通道。
- 航线浮标或航标杆：夜间点灯，同时缓解夜间对比偏低。
- 验收：
  - 总览图上能读出“一片群岛”；
  - 岛间航行仍畅通，往返时长不明显变长；
  - 船体通行检查通过。

### 阶段 2：岛形与路线 `complete`（2026-11-03，[证据](evidence/2026-11-03-archipelago/evidence.md#阶段-2岛形与路线)）

- 三座岛的海岸加入岬角、小湾和露岩台地，不再是光滑椭圆。海面、泡沫、岸岩、植被随新边界重排。
- 路线由菱形、六边形折线改为随地形弯曲的曲线小径。泊位、地标点、路线端点不动。
- 每岛码头旁保留一处沙湾或卵石滩，与主岛的沙岸语言一致。
- 验收：
  - 面积比例在范围内；
  - 全路径双向可走；
  - 岩块不进可航行水域；
  - 邻岛基线按新布局更新并记录。

## 内容草案（阶段 3，2026-11-03 用户确认）

总原则：
- 复用已有系统：背包、采集、手账、工坊配方、拍照题材、鱼簿。
- 每岛一个主题、2–3 个互动，收获能在主岛用掉或看到。

| 岛 | 主题 | 互动 | 带回主岛 |
|---|---|---|---|
| 雾松 | 雾中深林 | ① 古松林下采雾松菌和松果（新增采集点）② 雾天在雾松码头钓雾鱼（海钓点） ③ 倒木树洞里拾到旧物（每日一次） | 雾松菌进背包，可在篝火烤；旧物摆进卧室架子 |
| 秋岚 | 季节林窗 | ① 拾枫叶、桦皮（新材料，随季节变化） ② 观景丘新增拍照题材“群岛全景” ③ 林窗里的小动物（松鼠或鸟），靠近时有反应，复用既有动物系统 | 工坊新配方：枫叶挂饰、桦皮相框，做成后摆在主岛 |
| 潮汐 | 礁岩潮池 | ① 潮池观察：每池一种潮池小生物（海星、寄居蟹、海葵），记入新的“潮池图鉴” ② 拾贝壳（新模型，多种贝壳） ③ 漂流物拾取 | 贝壳摆在鱼缸旁或沙堡上；潮池图鉴进地点面板 |
