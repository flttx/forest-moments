## 1. 作品概述
中文名：森林拾光。英文名：Forest Moments。拟提交题目：一座会生长的童话森林。
作品目标：以小规模手绘风森林微型世界传递安静、自然、舒适的慢生活体验。玩家化身小浣熊穿行树林，在池塘钓鱼，种树、划船、照顾动物、到工坊制作物品、登瞭望塔看日落。互动不靠长任务清单，而让森林逐渐留下玩家的生活痕迹。

## 2. 创意与核心亮点（设计目标）
1. 小而精的森林空间：用有限地标与林间道路创造环形探索节奏，不堆砌建筑。
2. 行为影响环境：新树苗成长、动物活动、夜灯变化、渔获记录。
3. 浣熊主角动作：骨骼绑定保证走、跑、坐、蹲、钓鱼、划桨与尾巴自然摆动。
4. 真实可玩：交互优先而非静态展示模型，让评委直接在浏览器体验。

上述 2、3 和大部分 4 仍是开发目标，不能当作已完成功能。

## 3. 场景规划
场景是一座海上的森林小岛，周围大海、自然海岸和地平线清晰可见。岛内独立淡水池塘与海水分离，环形土路连接木作工坊、小牧场、木质瞭望塔、码头、木船和种树区。主色为深绿色针叶树与暖木、琥珀光和柔和岩石，建筑少而精。

先整理参考图，建立风格和单体造型基线；再独立生成整体概念图。当前空间候选为 [海上小岛概念 v2](../references/concept/forest-moments-overview-v2.png)，v1 未呈现大海，已替代。本轮完成 9 张适配专题图，原 35 张中保留 15 张作为当前单体依据、20 张转为历史。当前环境总板 v3、专题主图及建模约束见 [索引](../references/README.md)，个别单体细节覆盖整体概念中的早期表达。这些图均为设计插画，待用户确认，不代表实际游戏截图。提示词、版本与复核见 [本轮证据](../evidence/P1/2026-10-21/reference-revision/evidence.md)。

## 4. 技术架构（已开始）
React + TypeScript + Vite + R3F / Three.js，Zustand 用于交互状态，本地 localStorage 存档。目标以纯静态构建部署到 modelscope.ai 的 Static Studio，访客设备通过 WebGL 渲染，不在服务器执行每帧三维渲染。

现有基础：单页 R3F Canvas、灰盒森林中接入四项 Lux3D 模型、跟随相机、既有 Mixamo 待机/走跑切换、基础平面碰撞、地点提示和一次种树苗存档。已增加码头上船、前后划、转向、停稳下船与恢复步行的最小闭环；另已接入西岸抛竿/提竿/张力收线/渔获鱼簿闭环；工坊和登塔完整玩法尚未实现。
