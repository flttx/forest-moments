## 0. 音频系统（用户追加，2026-10-26，已实现，见 `docs/evidence/2026-10-26-audio/`）

参考本机 my-blog 的世界音频（`src/world/audio/`）移植，音效文件直接复用：

- **素材**：46 个 MP3，共 1.06 MB，均为 CC0（Kenney 三个音效包 + 逐条在页面上核验过的 Freesound 录音），来源记录照搬 my-blog 的 `assets/audio/sources.json`，归档到 `docs/evidence/assets/2026-10-26-audio/`。本轮没有重新联网核验许可。
- **引擎**：WebAudio，首次点击或按键后才创建（浏览器规定）。音乐、环境、音效三条总线加总音量；环境声循环交叉淡化，不会有接缝咔哒声；风声和室内底噪用噪声合成；进入室内时环境声低通变闷；标签页切到后台时静音。
- **设置**：工具条新增声音按钮，可静音（也可按 M）并调四个音量，记在本机。
- **场景声**：白天鸟鸣、夜晚虫鸣、黄昏两者交叉；靠近海边和划船时有海浪；白天海边偶尔有海鸥；牧场的鸡和羊按所在位置发出叫声（立体定位）；昼夜各一首背景音乐；篝火点燃时靠近能听到噼啪声（噪声合成）。
- **动作声**：脚步按速度起落，草地、桥、码头、室内地板各用对应的声音；划桨；钓鱼的抛竿、落水、咬钩、收线、出水；进出门；捡木墩、刨木、完成；添料、坐下、栽种；鱼放入鱼缸或放回池塘；打开和关闭面板。
- **实现**：游戏逻辑里不直接调用音频。由一个声音导演组件对比每帧前后的游戏状态，再决定播放什么；这部分逻辑写成纯函数，可以单测。
- **验收**：单测覆盖混音、设置读写和状态变化对应的音效；浏览器脚本确认解锁、解码和主要玩法触发了对应音效，且没有报错。无头浏览器听不到声音，需要用户实际试听。

## 1. 为什么做这两件事

现有玩法（钓鱼、种树、牧场、工坊、瞭望塔、划船、卧室日出日落、篝火、座椅）彼此独立，大多做一次就结束，玩家再进来时没有新目标。

- **手账**：每页给 3 件轻松小事，把现有玩法串起来，给它们一个“再来一次”的理由。
- **拍照模式**：把画面升级的成果变成玩家能主动使用的玩法，也直接服务参赛展示（截图、视频素材）。

两件事都**不需要新模型或新动作**，只用界面、存档、镜头和后期效果；声音由第 0 节的音频系统提供。两者互相联动：拍照本身是手账任务，填满手账页能解锁新滤镜和相框。

符合 PRD：慢生活、无数值经营、无失败惩罚、不绑定电脑时钟。

## 2. 小岛手账

### 2.1 规则

- 菜单新增“手账”（与地点、鱼簿、帮助并列）。打开时和其他面板一样暂停操作。
- 每页 3 件小事，从任务池里抽取，同一页不重复。
- 小事完成时弹一条普通提示（4 秒消失），手账里对应一行打勾。
- 3 件都完成后盖一枚印章，当场就能翻下一页，**不用等到第二天**。
- 已盖的印章按页保留，可以回翻查看。
- 每填满 2 页解锁一个拍照滤镜或相框（见 3.4），一共 6 档，约 12 页解锁完。之后继续盖印章，只是不再解锁新东西。

### 2.2 任务池（都可以重复完成，只用现有玩法）

| 任务 | 完成条件 | 触发点 |
| --- | --- | --- |
| 钓到一条锦鲤 | 任意渔获 | 钓鱼进入“钓到” |
| 钓到 30 cm 以上的锦鲤 | 渔获 ≥ 30 cm | 同上 |
| 给鱼缸添一位新住客 | 放入鱼缸（池边或卧室） | keepCatch / keepFish |
| 给鸡和羊添一次料 | 一餐吃完 | 喂养完成 |
| 点燃篝火，坐着烤一会儿火 | 篝火点燃时在营地座位坐满 8 秒 | 坐下状态计时 |
| 去海边坐一坐 | 在落日海湾或礁石观赏点坐下 | 坐下 |
| 登上瞭望塔看看 | 进入观景 | 瞭望塔 |
| 划船出海 40 米 | 一次出海累计划行 40 m | 船位移累计 |
| 睡一觉，看一次日出或日落 | 完成一次休息过渡 | wakeUp |
| 拍一张照片 | 拍照模式按下快门 | 拍照 |
| 在夜里拍一张照片 | 夜晚时段按下快门 | 拍照 |
| 去看看小树 | 种下小树，或观察已种的树 | 栽种 / 观察 |

工坊修木墩凳是一次性的，不放进任务池。抽题时排除当前状态做不了的任务（比如鱼缸满 5 条时不出“添新住客”）。

### 2.3 界面

- 手账面板沿用纸面风格：页码、3 行小事（未完成为空心框，完成后打勾并写上完成时刻）、页底一枚印章位。
- 印章用 SVG 绘制，按页轮换图案：松果、锦鲤、灯笼、羽毛、小船、月亮。
- 工具条上的手账按钮显示当前页进度（如 1/3），不加红点和动画催促。
- 中英文文案都补全，沿用现有 i18n 的类型检查。

### 2.4 存档

- 本机 `localStorage`，键名 `forest-moments:journal:v1`，当前格式为 `{ version: 1, page: { number, tasks: [{ id, progress, doneAt }] }, stamps: [{ page, stamp, doneAt, tasks? }] }`。新完成页保存完整任务；旧印章允许没有任务明细。解锁数据留待 P2。
- 初次抽页、任务完成及翻页时保存；连续活动的未完成计数只在当前会话有效，刷新清零，不逐帧写存档。
- 坏档时从新的一页开始；存档失败时本次会话照常可玩，并给一条错误提示（与现有存档失败处理一致）。

## 3. 拍照模式

### 3.1 进入与退出

- 进入：P 键，或工具条上的相机按钮。步行、坐着、船上（停靠或航行中）、瞭望塔观景时都可以进入；钓鱼、刨木、睡觉过渡中不能进入（按钮置灰并说明原因）。
- 进入后：角色和玩法计时暂停（与打开面板相同），界面只留拍照工具条。
- 退出：Esc、P，或工具条上的关闭按钮；退出后镜头回到进入前的位置。

### 3.2 取景

- **默认：环绕浣熊**。右键拖动转向，滚轮远近，Q/E 环绕，沿用现有镜头控制，范围放宽到俯仰 -10°～80°、距离 0.8～20 m。
- **可选：自由取景**（待确认，见第 5 节）。WASD 平移相机，限制在浣熊周围 15 m 内，不穿地面、建筑、树冠，复用现有镜头碰撞和避让。
- 可选“隐藏浣熊”，用于拍纯风景。
- 时段预览：白天、黄昏、夜晚可以临时切换，只用于拍照，退出后恢复，不写入存档。

### 3.3 拍摄与相册

- 快门：空格或快门按钮。画面轻微白闪（减少动态效果时不闪），并播放快门声（走第 0 节的音频系统）。
- 照片按当前画面分辨率输出，加上所选滤镜和相框。
- 每张照片可以直接下载 PNG；同时存入本机相册，保留最近 12 张缩略图和原图，存在 IndexedDB，`localStorage` 容量不够。
- 菜单里的相册：网格浏览，可下载或删除。浏览器不允许存储时，只提供下载并提示。

### 3.4 滤镜与相框

| 档位 | 内容 | 获得方式 |
| --- | --- | --- |
| 原色 | 当前画面 | 默认 |
| 暖阳 | 偏暖、提亮 | 默认 |
| 景深 | 对焦浣熊，背景虚化（`@react-three/postprocessing` 的 DepthOfField） | 手账第 2 页 |
| 胶片 | 轻微颗粒、褪色、暖暗角 | 手账第 4 页 |
| 纸边相框 | 米色纸边，右下角写“森林拾光”和日期（霞鹜文楷） | 手账第 6 页 |
| 黑白 | 柔和黑白 | 手账第 8 页 |
| 夜灯 | 加强灯光泛光，适合夜景 | 手账第 10 页 |
| 印章相框 | 相框角落盖上已获得的手账印章 | 手账第 12 页 |

低画质档（`?quality=low` 或自动降档）下关闭景深，避免掉帧。
