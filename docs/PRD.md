# 森林拾光 Forest Moments · 产品需求文档 v0.1

更新：2026-10-21｜状态：初稿｜类型：PC 浏览器 3D 休闲生活微型世界

## 1. 主题与愿景
森间拾光：海上一座会慢慢生长的童话森林小岛。周围大海、自然海岸与岛内独立淡水池塘共同构成场景。以小而精的地图、手绘感风格和可互动的慢生活为核心。玩家操作浣熊，3–5 分钟能触达核心地标，但能通过日常互动留下痕迹。拒绝大型开放世界、复杂数值经营和堆叠建筑。

## 2. 目标用户与体验
面向希望短暂放松、喜欢自然与可爱角色、愿意探索小世界的 PC 玩家。典型体验：林间漫步 → 发现工坊/牧场/池塘 → 种树 → 钓鱼 → 划独木舟 → 黄昏登塔观景。

## 3. 地标
- 工坊：可走近的小木屋，收集一两类资源后制作小物。
- 路灯：木灯柱，夜幕下温暖的琥珀光。
- 树木：环境以松树为主，少量阔叶，路径两侧疏密分区；可种植树统一为阔叶树，设计为初栽、幼树、成树三阶段（成长玩法尚未实现）。
- 养殖场：小围栏和几只动物，喂养/巡游反馈。
- 瞭望塔：低体量开放式木塔，底部不设封闭石砌房间；观景点和镜头切换。
- 池塘：鱼、水波、钓点、码头；小船可操作。
尽量不要再增加大量房屋。鸟瞰清楚，近景有层次。

## 4. 优先级与完成标准

| 模块 | P0 实际状态 | 交付验收 |
| --- | --- | --- |
| 角色移动与镜头 | 灰盒移动与跟随代码已写入，待试玩 | 不穿水/主要实体，走跑镜头平稳，动画流畅，尾巴自然 |
| 六处地标 | 静态几何占位、互动提示 | 地图可完整走通、交互点可达、无卡死 |
| 种树 | 一次种植与本地持久化代码已写入 | 多阶段成长、跨刷新保留、明确反馈 |
| 钓鱼 | 未开发 | 抛竿→等待→咬钩→收线→渔获/图鉴，完整可重复 |
| 划船 | 静态码头占位 | 上船、前后划、转向、下船和水面反馈 |
| 养殖 | 围栏占位 | 动物巡游与至少一种互动 |
| 工坊 | 小屋占位 | 简单材料→制作→获得物品闭环 |
| 瞭望 | 木塔外观占位 | 可进入观景状态并正常退出 |
| 环境 | 灯光/树木灰盒 | 柔和日落、夜灯、水波、树叶随风、音效与关闭动态效果 |
| 参赛 | 未部署 | 公开可访问的 Demo + 有过程截图、资产对比的 PDF/PPT |

## 5. 非功能约束
- Windows / PC 的现代 Chromium 浏览器优先；移动端后续再适配，不能把当前小屏 UI 等同完整触屏控制。
- 纯前端 Vite Static 版本，存档优先 localStorage，不依赖 Next.js 服务端。
- 重复树石优先 Instancing；GLB 和贴图优化后才发布；建立真实浏览器性能基线再锁定 FPS。
- 输入、UI、键盘焦点、减少动画设置和无 WebGL 时降级要逐步补齐。
- 第三方模型来源和商业授权必须逐项记录，活动赠送积分生成的模型也不可默认认为可商用。

## 6. 交付阶段
P0 项目初始化和灰盒；P1 风格与地图；P2 浣熊模型/自然动作；P3 种树和钓鱼；P4 船、动物、工坊、观景；P5 质感、音画、性能；P6 国际站发布与报告终版。

## 7. 非目标
不制作多人生存、大型经营、复杂战斗、大地图无缝探索、博客 CMS 或云端账号系统。
