# 森林拾光 UI 整体升级方案

日期：2026-10-25

状态：**已实施（2026-10-25），完成本机限定验证，用户查看通过**。实现与验证见 [U 证据](evidence/2026-10-25-ui-upgrade/evidence.md)；入场动画因引起长帧已去掉，见证据中的“性能修正”。2026-10-25 起作为 U 轨道并入 [场景视觉整体升级计划](VISUAL_UPGRADE_PLAN.md) 排期，内容不变。

2026-10-26 用户范围修订：仅 PC 浏览器，键鼠操作；不兼容手机界面，不开发手机布局或触屏控制。下方分辨率均为 PC 窗口验收，历史手机截图不代表移动端支持承诺。

## 1. 方向与目标

采用已确认的**轻手绘纸感、首次引导＋按需提示**。让场景成为主体，减少常驻面板、长说明和重复按键提示，覆盖主界面、所有玩法 HUD、通知、加载与错误界面。

打开帮助、地点、鱼簿或鱼缸面板时，暂停角色操作和当前玩法计时，关闭后继续。

用户已确认的选择：

- 视觉：轻手绘纸感。
- 提示密度：首次引导＋按需提示。
- 菜单行为：暂时停住，关闭后继续。

## 2. 界面与内容

- **主界面**：左上只留小号“森林拾光”；右上保留“地点 / 鱼簿 / 帮助”三个轻量入口。移除大标题卡、英文眉题、介绍段落、常驻地点列表及原型角标。
- **首次引导**：场景准备好后显示“WASD 移动 · 右键 视角 · 滚轮 缩放”，8 秒后收起，也可手动关闭。本机仅首次显示；完整键位随时从帮助查看，存储不可用时不阻塞游戏。
- **附近互动**：底部中央只显示一个主要动作，如“F 坐下”“F 进入卧室”。尚未到操作位置时显示一句指引，如“走近床边”，不显示误导性的可用按钮。
- **地点与鱼簿**：收进右侧纸面面板，分别展示简短地点信息、已有渔获记录。地点不新增传送或导航功能；空鱼簿仅提示“还没有渔获”。
- **统一风格**：暖米白底、深苔绿文字、暖灰细边、少量琥珀强调；轻微不规则边角体现纸感，不使用厚重木框、大片毛玻璃或额外装饰插画。正文不小于 14 px，按钮高度至少 36 px。

## 3. 玩法提示规则

- **钓鱼**：等待时只显示“等待咬钩”；咬钩时突出“F 提竿”；收线时保留进度、张力及“按住空格收线”，张力高时改为“松开空格”。结果只在玩法卡中出现一次。
- **木工**：保留步骤、节奏条和当前反馈；提示缩为“绿色区按 F”，去掉重复材料说明。材料需求仅在缺材料时提示。
- **种植、喂养**：进行中显示短状态和必要进度；次数、成长详情仅在主动查看时展示。
- **划船、观景、坐下**：首次进入显示简短专用操作；之后只保留当前可执行动作和必要边界提醒，不再同时出现底部说明条与交互卡。
- **卧室与鱼缸**：远离家具时不显示常驻指引；鱼缸保留容量、鱼列表、“放入 / 放归”及简短空状态。
- **日出日落**：只留“日出”或“日落”小标题及“跳过”入口，移除描述段落和进度条。
- **通知**：普通结果用一句短提示，4 秒后消失；相同事件不在多处重复展示。存档失败、加载错误保留明确原因和关闭或重试入口，不自动消失。加载文案简化为“正在进入小岛…”。

## 4. 实现与输入边界

- 将 `src/App.tsx` 中分散的界面选择收敛为统一 HUD 容器，复用动作提示、按键标签、纸面面板和通知组件；各玩法继续使用原有交互函数。
- 新增独立 UI 状态管理：当前面板、引导完成状态；鱼缸接入统一面板互斥规则。通知明确区分普通反馈与错误，不通过匹配中文内容判断重要程度。
- 展开面板时清空移动键、收线按住状态和鼠标拖拽；暂停移动、船体推进与钓鱼、木工等玩法计时。环境动画继续，树木按真实时间成长的既有规则保留。
- 关闭面板后恢复原玩法，不重置进度、不自动重新按住收线。Esc 优先关闭面板，不能同时触发退出钓鱼或起身；面板支持焦点约束，关闭后恢复焦点。
- 转场与睡眠期间收起菜单入口；全岛远景继续保持简洁。面板内部可滚动，滚轮和按键不穿透到场景。
- 保留现有玩法存档和快捷键，不新增 UI 依赖、模型、付费资源或部署步骤。

## 5. 验证与交付要求（实施后执行）

- 单测覆盖提示优先级、动作可用性、通知寿命、面板互斥，以及暂停前后玩法进度不丢失、不跳时。
- 实机检查首次进入与刷新、各玩法阶段、鱼缸操作、错误提示，以及“按住移动时开菜单”“咬钩时打开帮助”“Esc 只关闭顶层面板”等输入场景。
- 检查白天、黄昏、夜晚和全岛远景；在 1920×1080、1280×720、1024×768 下确认文字清晰、面板不重叠、主要场景无遮挡，支持减少动态效果。
- 执行 `pnpm lint`、`pnpm test`、`pnpm build`，更新依赖旧文案和 DOM 的浏览器验证，保留实际交互断言。
- 保存同机位前后截图；同步更新进度、PRD、项目报告和证据，明确记录已验证结果与剩余问题。
