# Forest Moments Visual QA

1. 首先阅读 docs/ART_DIRECTION.md 和 docs/PRD.md，并核对 PROGRESS.md 的已确认美术方向。
2. 对本轮实际运行代码启动本地预览，录制昼/夕/夜、鸟瞰、近景、角色、工坊、池塘、牧场、瞭望塔的关键视角，报告浏览器分辨率和版本。
3. 查找硬边、重复树形、糊贴图、遮挡、穿模、镜头抖动、UI 重叠、动画不自然和尾巴僵硬等问题。用相同机位、相同时段前后截图比较。
4. 能做真实自动化检查时运行相关截图和轨迹脚本；没有浏览器可用时标为「未实机视觉验收」，不能声称 PASS。
5. 将实际截图、修复前后对比和结论存至 docs/evidence/；按 AGENTS.md 更新报告书，未通过项不可伪造验收。
