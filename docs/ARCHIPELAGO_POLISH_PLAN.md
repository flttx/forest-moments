# 群岛整合与美术打磨计划

更新：2026-11-03｜状态：阶段 1–4 完成；阶段 5 已实现，西林路线实测 0 遮挡，全量回归通过（镜头手感待用户确认）｜发现记录：[ARCHIPELAGO_POLISH_FINDINGS.md](ARCHIPELAGO_POLISH_FINDINGS.md)｜会话日志：[PROGRESS.md](../PROGRESS.md)

## 目标

1. 让雾松、秋岚、潮汐三座小岛和主岛连成一个群岛世界，不再是几块各自独立的海中陆块。
2. 让每座小岛有值得停留的内容：轻玩法加布景，收获能带回主岛。
3. 完成美术清单：
   - 西林树冠挡镜头；
   - 树形重复、缺小树形态；
   - 连续礁岸；
   - 岸岩远看偏小、夜间对比偏低；
   - 潮汐贝壳；
   - 赤杨；
   - 主岛内陆起伏偏缓。

| 顺序 | 先做群岛，再做美术清单 |

## 约束

- 仅 PC 浏览器。纯前端静态。
- 旧存档必须兼容。新增存档字段要能缺省解码。
- 泊位坐标、往返流程、刷新回到安全泊位不变。
- 小岛面积比例保持：雾松、秋岚各为原主岛的 20%–25%，潮汐为 12%–18%。
- 重塑岛形会改变邻岛逐坐标基线（tideCoast、autumnTravel、autumnUnderstory 等）。用户选择了“岛形规整”这一项，视为同意更新邻岛基线；更新时在证据中记录前后差异。
- 岛形函数的 TS 与 GLSL 两份必须同步：海面浅水、泡沫与岛地形共用同一条边界。
- 每阶段都要过 lint、test、build，并采集实机静音截图。改到玩法时，跑相应的真实键鼠检查。
