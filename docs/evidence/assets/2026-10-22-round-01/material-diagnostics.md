## 浣熊材质候选

`assets/lux3d/round-01/raccoon/material-v1.glb` 仅修改 GLB JSON 中一个材质的 PBR 设置：禁用原 metallic/roughness 贴图引用，金属度改为 0、粗糙度设为 0.68。原贴图仍嵌在文件中，没有删除或压缩。脚本断言除 materials 外的 JSON 完全一致，全部二进制 chunk 逐字节相同，因此顶点、索引、法线、UV、图像内容保持不变；仍为 **299138 三角面**。

Blender 使用原稿边界、同机位、相同灯光与采样渲染了正面/侧面/背面。实际查看后，手臂、披肩和鞋面的强高光降低，色彩图案和轮廓保留；由于这是统一粗糙度，眼部与皮革的材质差别也变弱，后续需分区保留眼部高光。作为对比候选保留，未定为最终材质，未做绑定或游戏替换。

## 原面数测量页

本地开发入口：[模型复核与测量](http://127.0.0.1:5176/scripts/aholo/review.html)。支持单项原稿、四项同时展示，以及浣熊原稿/材质候选切换。四项展示使用原始 GLB，均未减面，不是整座游戏场景。

- 测量按钮先预热 2 秒，再固定机位采样 30 秒，输出平均 RAF 帧率、帧间隔 p50/p95/max、draw calls 和渲染三角面；可下载 JSON。
- 切换资产/机位、改变视口、进入后台会取消采样并使旧结果失效。测试时关闭手动相机操作。
- 记录浏览器 UA、Three.js 版本、实际绘图缓冲尺寸、DPR、机位、源文件记录哈希、加载/解析/场景准备时间。加载时间缓存状态未知，也不包含首次 GPU 上传。
- `resourceCounts` 只是 geometry/texture 资源个数，不能称作显存；`gpuMemoryBytes` 明确为空。帧率受屏幕刷新率和主线程调度影响，不等于 GPU 耗时。
- HTML、Vite 转换后的模块和 manifest 返回 HTTP 200；本轮浏览器控制工具仍返回空列表。**尚未实际点击或测量，没有真实 FPS、显存或浏览器截图。**
