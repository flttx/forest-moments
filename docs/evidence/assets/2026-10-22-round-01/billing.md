## 余额接口调查

官方当前客户端定义 `GET /lux3d/v1/account/balance?source=1`，使用所选区域 API Key。2026-10-22 使用当前中国区密钥实查两次，均返回 HTTP 500（HTML），没有获得 `availableCredits` 数值。此错误不代表零余额，也不代表生成免费。

- [官方账户查询实现](https://github.com/manycore-research/Aholo-Lux3D/blob/master/plugins/common/aholo-lux3d/core/runtime/commerce_client.py)
- [官方区域及密钥说明](https://github.com/manycore-research/Aholo-Lux3D/blob/master/README.md)

官方明确两区密钥不互换；本轮没有全球区密钥或跨区余额比对，因此不从这张单账户 API 账单推导跨区积分可转移政策。仅记录用户观察，不新增区域政策保证。
