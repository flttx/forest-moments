# 点篝火卡顿 · 证据（2026-10-28）

- 现象：点燃篝火时画面卡一下，然后火才出现。
- 测量（隔离无头 Edge，夜晚，站在篝火旁，点火前后 120 帧）：点火那一帧 2535 ms（平时 5 ms）。
- 原因：火焰、火星和点光源平时 `visible=false`，点着才第一次参与渲染。场景里点光源数量变化，所有受光材质的着色器要重新编译，火焰自己的着色器和几何体也是第一次使用。
- 修复：火焰、火星、点光源始终留在场景里。熄灭时点光源强度为 0，火焰与火星的着色器丢弃全部像素（`lit` 参数）；加载时在熄灭状态下先 `gl.compile` 一次。点火只是把参数切到 1。
- 结果：点火那一帧 7 ms（修复前 2535 ms；只靠预编译、仍用 `visible` 切换时 93 ms，几何体首次上传的那部分靠常驻去掉）。
- 截图：`unlit.png`（熄灭，只剩木柴余烬）、`lit.png`（点着后火焰与暖光）。
- 代价：场景里永久多一盏强度为 0 的点光源（原本只在点火后才有）。
- 限制：未人工试玩；无头 Edge 与你的显卡/驱动编译耗时不同，实际卡顿时长会不同，但这次的原因是确定的。
