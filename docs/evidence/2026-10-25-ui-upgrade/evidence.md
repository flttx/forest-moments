# U 轨道：整体 UI 升级 · 2026-10-25

按已确认的 [UI 升级方案](../../UI_UPGRADE_PLAN.md) 实施，是[场景视觉升级计划](../../VISUAL_UPGRADE_PLAN.md) 的第三阶段。改前界面见 [V2 改后截图](../2026-10-25-visual-v2/after/00-default-hud.png)（同场景、旧界面），改后见 `after/02-default.png`。

## 改动

- **统一 HUD 容器**（`src/Hud.tsx`）：`App.tsx` 只剩场景、加载提示、转场遮罩和 `<Hud/>`。移除大标题卡、英文眉题、介绍段落、常驻地点列表、底部键位条和原型角标。左上只留小号“森林拾光”，右上是“地点 / 鱼簿 / 帮助”三个入口；转场和睡眠期间入口收起，全岛远景时小标题收起。
- **纸面风格**（`src/App.css`）：暖米白底、深苔绿文字、暖灰细边、少量琥珀强调，边角用不对称圆角体现轻微手绘感；没有厚木框、大片毛玻璃或装饰插画。正文不小于 14px，按钮高度不小于 36px。
- **底部唯一提示**（`src/game/prompt.ts`）：按 `interact()` 的判断顺序，只给出“F + 动作”“指引”“进行中状态”三者之一。没到操作位置时只显示一句指引、不显示按钮；此时按 F 也不再弹出重复的提示通知。卧室里远离家具时没有常驻指引；工坊只在缺材料时才提材料。
- **首次引导与模式首次提示**（`src/game/uiStore.ts`）：模型就绪后显示“WASD 移动 · 右键 视角 · 滚轮 缩放”，8 秒后或手动关闭；划船、观景、坐下第一次进入时各显示一行专用操作。两者都记在本机，存储不可用时只在本次会话生效，不阻塞游戏。
- **菜单暂停**：打开地点、鱼簿或帮助面板时，store 置 `menuPaused`。此时移动与船体推进停止，钓鱼、木工、栽种、添料、坐下计时冻结，收线按住被释放，鼠标拖拽和滚轮被停用；`interact()` 也被拦下。关闭后从原处继续，不重置、不跳时，也不会自动重新按住。环境动画和树木真实时间成长照常。
- **面板互斥与键盘**：面板与鱼缸互相替换。面板打开时由它接管键盘，Esc 只关闭最上层面板，不会同时收起钓竿或起身；Tab 焦点限制在面板内，关闭后焦点回到触发按钮（仅键盘打开时显示焦点框）。滚轮不会穿透到场景。
- **各玩法卡片**：钓鱼等待时只显示“等待咬钩”；咬钩时卡片变为琥珀色并突出“F 提竿”；收线时显示进度和张力，张力高时按钮改为“松开 Space”。结果只在卡片里出现一次，不再另发通知。木工只留步骤、节奏条、反馈，提示缩为“绿色区按 F”。睡眠只显示“日出 / 日落”和“跳过”。鱼缸保留容量、鱼列表、“放入 / 放归”和空状态。
- **通知**：store 新增 `messageKind`。保存失败、加载失败显式标为 error，一直保留到关闭；其余为普通反馈，4 秒后消失。不再靠匹配中文判断重要程度。加载文案简化为“正在进入小岛…”。
- **性能修正**：最初给引导和通知加了入场动画（淡入 + 位移）。帧时间测出白天出现 140–212 ms 的长帧；对照“引导预先关闭”和“引导照常出现但禁用动画”两种情况，都回到约 55 ms，确认原因是动画层叠在 WebGL 画布上方，因此去掉了入场动画。
